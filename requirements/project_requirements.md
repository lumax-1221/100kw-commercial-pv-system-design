# 项目需求与假设

## 1. 客户场景

假设客户是一栋位于青岛的工商业厂房，希望利用约 800 m² 的彩钢瓦/平屋顶建设一套并网光伏系统。客户更关注配置是否容易解释、设备是否匹配、屋顶是否放得下，以及方案是否便于后续维护。

## 2. 冻结输入

| 类别 | 取值 | 说明 |
|---|---:|---|
| 地点 | 青岛 | 个人虚拟场景，不代表真实项目 |
| 屋顶可用面积 | 800 m² | 仅做数量级复核，不替代排布图 |
| 交流侧目标 | 100 kW | 380/400 V，三相并网 |
| 系统类型 | 并网、无储能 | 不讨论储能调度 |
| 最低电池片温度 | -10 °C | 课程项目假设，需后续用气象/设计温度确认 |
| 最高电池片温度 | 70 °C | 课程项目假设，不等同于环境温度 |
| 屋顶面积利用系数 | 1.25 | 组件净面积 × 1.25，覆盖通道和检修余量的粗略估算 |
| 设计目标 | 可解释、匹配、易维护 | 不是追求单一指标最大化 |

## 3. 范围

包含组件与逆变器的公开参数整理、组串数量、MPPT 分配、直流容量、容量比和屋顶面积初核，以及三套配置的定性比较。

不包含结构承载、组件排布施工图、线缆截面、保护整定、防雷接地、并网审批、报价、融资、税费和真实项目收益承诺。

## 4. 计算口径

温度修正使用：

```text
Voc_cold = Voc_STC × [1 + beta_Voc × (Tmin - 25)]
Vmp_hot  = Vmp_STC × [1 + beta_Vmp × (Tmax - 25)]
```

组串通过条件：

```text
Nseries × Voc_cold ≤ Vdc_max
Nseries × Vmp_hot  ≥ Vmppt_min
Nparallel × Imp    ≤ I_mppt_max
Nparallel × Isc    ≤ I_sc_mppt_max
```

其中温度系数在表格内用小数表示，例如 -0.25%/°C 写为 -0.0025。
